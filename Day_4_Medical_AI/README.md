## 🚀 Mini Project

### Medical Image Processing Toolkit

The toolkit loads an X-ray image and performs:

X-Ray
  ↓
Resize
  ↓
Grayscale
  ↓
Gaussian Blur
  ↓
Canny Edge Detection
  ↓
Thresholding
  ↓
Rotation / Flipping
  ↓
Save Outputs
Processed images are saved in the outputs folder.

Image preprocessing helps prepare medical images for further computer vision and Medical AI tasks by reducing noise, standardizing image size, and highlighting useful image features.
