# 🩺 Medical AI Analysis Toolkit

> An integrated mini project combining Python, NumPy, Pandas, Matplotlib, and OpenCV for basic medical data and image analysis.

## 📌 Overview

This project combines the skills I learned during my Medical AI Journey into one workflow.

It uses a synthetic patient dataset and a sample X-ray image to demonstrate basic data analysis, visualization, and medical image preprocessing.

- NumPy
- Pandas
- Matplotlib

📊 What the Project Does
Patient Data Analysis
Loads synthetic patient data using Pandas
Calculates statistics using NumPy
Visualizes heart-rate data using Matplotlib
Medical Image Processing
Loads an X-ray using OpenCV
Resizes the image
Converts the image to grayscale
Applies Gaussian Blur
Performs Canny Edge Detection
Saves processed images
📄 Analysis Report

The program automatically generates an analysis_report.txt containing the calculated statistics and image-processing steps.

🎯 Learning Outcome

This project helped me combine Python, NumPy, Pandas, Matplotlib, and OpenCV into a single Medical AI workflow.

It also helped me understand how data analysis and image preprocessing can be used as foundations for future Medical AI projects.

Note: This is an educational project using synthetic patient data. It is not a medical diagnostic system.
